# 🌸 My Flower Gallery

A simple flower gallery webpage created using HTML.

## 📖 About Project

This project is a basic flower gallery that displays different flower images with styled text using HTML font attributes.

## ✨ Features

- Flower Image Gallery
- Colorful Text Styling
- Different Font Sizes
- Simple and Clean Layout
- Beginner-Friendly HTML Project

## 🛠 Technologies Used

- HTML5
- Font Tag Attributes
  - face
  - color
  - size

## 🎯 Purpose

This project was created to practice:
- HTML Structure
- Image Insertion
- Text Formatting
- Basic Web Page Design
